# Sistema de Blog por Consola (POO y Persistencia JSON)

Proyecto refactorizado a Programación Orientada a Objetos y persistencia en archivo `posts.json`.

## Estructura del proyecto
- `blog/modelos.py`: Clases `Autor`, `Post` y `Blog`.
- `blog/datos.py`: Funciones para serializar/deserializar objetos hacia y desde `posts.json`.
- `blog/menu.py`: Captura y validación de entrada por consola.
- `main.py`: Punto de entrada del programa.

## Ejecución
```bash
python main.py
